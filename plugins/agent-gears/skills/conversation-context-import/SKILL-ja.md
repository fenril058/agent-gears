# 対話コンテキストのimport手順書

`.dev/contexts/` に保存された過去の対話コンテキストを読み込む。

## 命名規約

カレントブランチのコンテキストは `.dev/contexts/{サニタイズ済みブランチ名}.md` に置かれる。
ブランチ名は `git branch --show-current` で取得する。
サニタイズ済みブランチ名とは、以下の文字をそれぞれ `-` に置換したものである:

```
/ \ : * ? " < > |
```

例: `dependabot/npm_and_yarn/feed-5.2.0` → `dependabot-npm_and_yarn-feed-5.2.0`

## 読み込み対象

ユーザーが指定したファイル、ブランチ、読込範囲を、既定の選択より優先する。
全件読込や過去ブランチの利用もこの指定に含む。
すでに得た許可を繰り返し求めない。
指定されたファイルやブランチのコンテキストがなければ、その旨を報告し、別のコンテキストへ黙って置き換えない。

一般的な文脈読込の依頼では、`.dev/contexts/*.md` を列挙し、次のように選ぶ:

- カレントブランチのファイルがあれば、他ブランチのファイルがあっても、質問せずにカレントブランチ分だけを読み込む。
- カレントブランチのファイルがなければ、依頼内容とファイル名から関連するコンテキストを特定する。
  対象が不明確なら、候補のファイル名を示し、内容を読む前に対象の特定に必要な点だけを確認する。
  他ブランチのファイルを全件読み込むことを既定にしない。
- コンテキストファイルがなければ、見つからない旨を報告して終了し、内容を捏造しない。

どのファイルを読み込んだかを報告する。

## 関連スキル

- **conversation-context-export**: 現在の対話コンテキストを `.dev/contexts/` に書き出すスキル。開発の区切りでコンテキストを保存する時に使用する。
