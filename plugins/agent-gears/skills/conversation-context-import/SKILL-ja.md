# 対話コンテキストのimport手順書

`.dev/contexts/` に保存された過去の対話コンテキストを読み込む。

## 命名規約

カレントブランチのコンテキストは `.dev/contexts/{サニタイズ済みブランチ名}.md` に置かれる。
ブランチ名は `git branch --show-current` で取得する。
サニタイズ済みブランチ名とは、以下の文字をそれぞれ `-` に置換したものである:

```
/ \ : * ? " < > |
```

例: `dependabot/npm_and_yarn/feed-5.2.0` → `dependabot-npm_and_yarn-feed-5.2.0`

## 読み込み対象

`.dev/contexts/*.md` を列挙し、存在状況で分岐する:

- **カレントブランチのファイルのみ** → 質問せずに読み込む。
- **他ブランチのファイルのみ** → 質問せずに全て読み込む。
- **両方** → AskUserQuestion でどちらを取るか聞く。カレントブランチのファイルのみか、
  `.dev/contexts/` 内の全ファイルか(選択肢にファイル名を列挙する)。
- **1つも無い** → コンテキストファイルが見つからない旨を報告して終了する。

どのファイルを読み込んだかを報告する。

## 関連スキル

- **conversation-context-export**: 現在の対話コンテキストを `.dev/contexts/` に書き出すスキル。開発の区切りでコンテキストを保存する時に使用する。
